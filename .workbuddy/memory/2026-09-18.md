## 第五轮：67 份包级 README + NuGet 内嵌配置（用户明确需求：发 NuGet 包要带 README）

```
resolve    用文件的【旧】位置把相对链接解析成仓库根相对路径

relativize 用文件的【新】位置重新算出相对路径
绝对 GitHub URL：只对 /docs/ 之后的部分做 map
```
