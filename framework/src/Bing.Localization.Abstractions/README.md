>

>
> **上游 Bing 包**：`Bing.Core`

---

## 这是什么

供上层工程引用本地化契约而不依赖实现。

## 安装

```bash
dotnet add package Bing.Localization.Abstractions
```

## 与其它包的关系

**本包依赖**：`Bing.Core`

**依赖本包**：`Bing.Localization`
