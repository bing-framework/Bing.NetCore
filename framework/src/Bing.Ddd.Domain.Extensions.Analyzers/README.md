# Bing.Ddd.Domain.Extensions.Analyzers
[![NuGet](https://img.shields.io/nuget/v/Bing.Ddd.Domain.Extensions.Analyzers.svg)](https://www.nuget.org/packages/Bing.Ddd.Domain.Extensions.Analyzers/) [![NuGet Downloads](https://img.shields.io/nuget/dt/Bing.Ddd.Domain.Extensions.Analyzers.svg)](https://www.nuget.org/packages/Bing.Ddd.Domain.Extensions.Analyzers/) ![TFM](https://img.shields.io/badge/TFM-netstandard2.0-blue.svg)

> 源代码生成器：为 `DomainObjectBase<T>` 派生类自动生成变更追踪代码。
>
> **目标框架**：`netstandard2.0` ｜ **分层**：L4 领域层 ｜ **当前版本**：7.0.0 ｜ **源文件**：2
>
> **上游 Bing 包**：无（本包是叶子/基础包）
>
> **三方依赖**：`Microsoft.CodeAnalysis.Analyzers`、`Microsoft.CodeAnalysis.CSharp`

---

## 这是什么

编译期为继承 `Bing.Domain.Entities.DomainObjectBase<T>` 的类生成 `partial` 变更追踪代码（含 `AddChanges` 等方法）。你的领域类需要声明为 `partial`。

## 安装

```bash
dotnet add package Bing.Ddd.Domain.Extensions.Analyzers
```

## 快速上手

```csharp
// 你的类（需 partial）
public partial class User : DomainObjectBase<User> { public string Name { get; set; } }

// 生成器自动产出 <auto-generated> 的 partial 部分，源码里找不到它
```

## 关键类型

| 类型 | 命名空间 | 说明 |
| --- | --- | --- |
| `ChangeTrackableSourceGenerator` | `Bing.Analyzers` | `[Generator] ISourceGenerator` |

## 与其它包的关系

**三方 NuGet**：`Microsoft.CodeAnalysis.Analyzers`、`Microsoft.CodeAnalysis.CSharp`

## 注意事项

生成的代码是 `<auto-generated>`，不要在源码目录里找它。触发条件：类为 `partial` 且基类确实是 `DomainObjectBase<T>`。
