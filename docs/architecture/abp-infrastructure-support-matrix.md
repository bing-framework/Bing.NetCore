## G01 语义边界

- Attribute 与 Admin 是两条独立路径。`CapTraceAttribute` 仅在显式声明并经过 AOP 代理时执行；Admin 的 `CapSubscribeInvoker` 依赖 CAP `8.0.1` 的真实 `ISubscribeInvoker.InvokeAsync` 异步调用边界恢复父上下文。
- `FromCap` 为 null/非 `CapHeader` 时，Attribute 仍调用 `next` 一次。CAP 原生参数绑定仍可能在调用目标前拒绝不支持的参数类型；本修复不改 CAP 绑定规则。
- 已取消 Task 的兼容逻辑使 Attribute 的管道 Task fault 并保留原取消异常与令牌；异常完成前先在 `finally` 恢复父引用，避免外层 Uow 把取消当成成功。
- 旧提交、新 scope 的示例源代码和行为测试见 [`Bing.Uow README`](../../framework/src/Bing.Uow/README.md) 与 [`UnitOfWorkDocumentationExamplesTest`](../../framework/tests/Bing.Uow.Tests/UnitOfWorkDocumentationExamplesTest.cs)。
