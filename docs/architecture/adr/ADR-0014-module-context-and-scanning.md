# ADR-0014：模块上下文与应用级扫描范围

- 状态：已实现；当前工作树。
- 日期：2026-09-28。

## 背景

模块初始化和关闭已使用短期服务作用域，注册阶段已有配置读取入口。原配置入口可能收窄合法的 `IConfiguration` 实现，通用单例读取还可能以空 provider 提前执行工厂。新应用默认只扫描已选模块的本体程序集，无法声明模块附加的服务程序集。

## 决策

生命周期上下文通过扩展方法从当前作用域获取配置和通用宿主环境，不增加全局应用容器。注册阶段只读取最后一个显式单例实例；缺失直接配置时允许从 `HostBuilderContext` 实例回退，不执行工厂或临时构建 DI 容器。

模块可通过 `BingModuleAssemblyAttribute` 声明附加程序集，应用可通过 `BingApplicationOptions.ServiceScanning` 添加程序集并筛选约定 DI 候选类型。扫描目录在配置前冻结，供约定 DI、选项绑定、公开类型事件和晚选项补扫使用；筛选器仅影响约定 DI。附加程序集不改变模块图或模块执行顺序。

插件加载器在临时解析回调有效期间完成模块图及附加程序集元数据预检，随后退订回调。附加程序集只来自默认上下文或当前插件代，跨代对象被拒绝。目录按实际程序集对象去重；同一程序集中的多个模块仍共享扫描边界。

## 后果

注册期读取配置工厂的旧副作用不再发生；依赖该行为的模块须改为显式实例，或在运行期从 DI 解析。显式附加程序集不可完整读取类型时注册失败，不静默跳过。新的扫描 API 不提供代码沙箱，用户持有插件程序集、描述符或类型仍可能阻止卸载。
