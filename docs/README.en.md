# Bing.NetCore — Documentation Map (English)

> **适用版本**：框架 `7.0.0`（`version.props`）｜ 目标框架：类库 `netstandard2.0`、Web / 应用 `net6.0`｜ 内容核对：2026-09-18｜ 版本历史见 [发行说明](ReleaseNotes.md)

**English** ｜ [简体中文](README.md)

The reference documentation for this framework is written in **Simplified Chinese**. This page is an
English **map** of that set: it tells you which document answers which question, so you can jump
straight to the right file (browsers translate Markdown reasonably well; the code and type names
obviously need no translation).

If you only read one document, read the usage guide. If you only read one *section*, read the
registration entry list — most confusion in this framework comes from guessing an `AddXxx` name wrong.

**Directory layout.** `docs/` is organised by topic (it is no longer flat). Paths in the table below
already include the subdirectory:

| Directory | Contents |
| --- | --- |
| `getting-started/` | Usage guide, ORM capability matrix, package index, glossary, API quick reference, ABP migration, troubleshooting |
| `architecture/` | Architecture, design rationale, subsystem deep dive, events & messaging, known gaps, `adr/` (10 decision records) |
| `guides/` | Domain modelling, extensibility, configuration, best practices, cross-cutting features, component packages, `recipes/` |
| `operations/` | Logging & observability, security, performance, testing, engineering/release, asset index |
| `sql/` · `testing/` · `migrations/` | Data-access deep dive, integration tests, cross-version upgrade |
| `api/` | **Generated by docfx — do not hand-edit.** The hand-maintained index lives in `getting-started/API速查索引.md` |

## Language policy

Chinese is the authoritative language for all reference documentation, XML doc comments and commit
messages. This English map exists so that non-Chinese readers can navigate the set; when the two
disagree, **the Chinese document wins**.

Contributions that add *new* English translations are welcome, but an English translation must
record the Chinese revision it was translated from — partially translated sets that silently drift
are worse than none.
