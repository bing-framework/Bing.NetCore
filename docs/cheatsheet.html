Bing.NetCore Cheat Sheet

从零到一个 CRUD API · 类型名取自源码 · 打印请横向或缩放至 60%

1. 最小宿主 Program.cs

var b = WebApplication.CreateBuilder(args);
b.Services.AddControllers().AddControllersAsServices();
b.Services.AddBing().AddModule<AppModule>();
var app = b.Build();
app.UseBing();          // 非 Web 用 serviceProvider.UseBing()
app.MapControllers();
app.Run();
AddBing() 在 IBingBuilder 上，不在 IServiceCollection 上。

2. 模块 AppModule

[ModuleLevel(ModuleLevel.Application)]
public class AppModule : BingModule
{
    public override void ConfigureServices(IServiceCollection s)
    {
        s.AddMySqlUnitOfWork<IAppUow, AppUow>(cfg => { }, b => { });
        s.EnableAop(o => o.ThrowAspectException = true);
    }
}
[DependsOnModule] 只保证加载，不管顺序；顺序看 ModuleLevel（Core1/Framework10/Application20/Business30）。

3. 实体

// AggregateRoot<T,K> 已自带 IVersion（乐观锁 Version 属性）
public class Order : AggregateRoot<Order, Guid>,
    ISoftDelete, IAuditedObject<Guid>
{
    public string No { get; set; }
    public bool IsDeleted { get; set; }
    public DateTime? CreationTime { get; set; }
    public Guid? CreatorId { get; set; }
    // IModificationAuditedObject / IDeletionAuditedObject 按需追加
}
接口 / 基类作用
AggregateRoot<T,K>聚合根，已含 IVersion（byte[] Version）
ISoftDelete软删除 + 查询自动过滤
IAuditedObject<K>创建/修改审计字段自动填充
EntityBase<T,K>不带软删除/审计的普通实体

4. 仓储（叫 IStore，不叫 IRepository）

public interface IOrderStore : IStore<Order, Guid> { }

public class OrderStore : StoreBase<Order, Guid>, IOrderStore
{
    public OrderStore(IUnitOfWorkManager uowm) : base(uowm) { }
    // 约定式 DI 自动注册，不用手写 AddScoped
}
只读路径注入 IQueryStore<T,K>（IStore 的父接口），语义更清晰。

5. 应用服务

public class OrderAppService : AppServiceBase, IOrderAppService
{
    private readonly IOrderStore _store;
    public OrderAppService(IOrderStore store) => _store = store;

    [UnitOfWork]
    public async Task<Guid> CreateAsync(OrderCreateDto dto)
    {
        var e = dto.MapTo<Order>();
        await _store.AddAsync(e);
        return e.Id;   // 切面在方法成功后自动 Commit
    }
}
🔴 [UnitOfWork] 是 AOP 拦截器 —— 没调 EnableAop(...) 就完全不生效，不报错但数据不落库。

6. Controller（返回值自动包装）

[ApiController, Route("api/orders")]
public class OrderController : ApiControllerBase
{
    private readonly IOrderAppService _app;
    public OrderController(IOrderAppService app) => _app = app;

    [HttpPost]
    public async Task<Guid> Create([FromBody] OrderCreateDto dto)
        => await _app.CreateAsync(dto);
    // 返回 {"code":..,"message":..,"data":..,"operationTime":..}
}
要返回原始结构（文件流等）加 [IgnoreResultHandler]。

7. 注册入口速查

能力入口
模块AddBing().AddModule<T>() / UseBing()
EF MySQLAddMySqlUnitOfWork
EF PostgreSQLAddPgSqlUnitOfWork（不是 PostgreSql）
EF SqlServer / Oracle / SqliteAddSqlServer/Oracle/SqliteUnitOfWork
FreeSQL MySQLAddMySqlUnitOfWork（命名空间 Bing.FreeSQL）
DapperAddSqlServerProvider() / AddMySqlProvider() …
AOPEnableAop（没有 AddAop）
JWTAddJwt(configuration)
事件总线AddDefaultEventBus / AddCapEventBus
分布式锁AddRedisDistributedLock
对象映射AddAutoMapper
邮件AddMailKit / AddSmtpEmail
缓存无入口 → RedisHelper.Initialization + AddScoped<ICache, CSRedisCacheManager>()
文本模板无入口 → 手动装配 BingTextTemplatingOptions

8. 五个最常见的坑

  1. 没有 AddCache / AddCaching：缓存必须手工注册。
  2. [DependsOnModule] 不排顺序：顺序由 ModuleLevel 决定。
  3. 非 Web 宿主漏 UseBing()：静默不初始化。
  4. 把 Bing.Data.Sql 当 ORM：它没有 IUnitOfWork / IStore / 审计。
  5. 事件总线混用：Bing.EventBus 是遗留包，别用它的 ILocalEventBus。
