# 模块化、依赖注入与资源生命周期专项排查

本文件记录用户在当前对话批准的实施计划。范围限定为现有模块注册、Microsoft DI、AspectCore 属性注入、插件代和资源释放路径；保持目标框架、依赖版本及公开契约。

1. 建立约定注册、多接口、生命周期与资源所有权直接测试；修复 `IAsyncDisposable` 扫描及可兼容修复的转发错误。
2. 使用真实容器验证构造、Lazy、工厂、作用域和 AspectCore 属性注入；危险循环放在受控子进程。区分构建期与运行期校验。
3. 验证注册、初始化、宿主停止和插件换代的异常、取消、并发和同步/异步释放。活动调用不响应取消时不得提前释放。
4. 进行 20 次预热及 100 次循环的资源探针，记录分配、托管堆、GC、进程内存、释放次数和弱引用回收结果。
5. 更新使用指南、问题分类、生产符号到测试方法映射和执行报告。

验收：直接复现每个确认问题；修复或记录兼容限制；Core、AspectCore、MVC 双框架测试及 WebApi 构建；记录实际 SDK 与未能使用锁定 SDK 8.0.424 的区别。
