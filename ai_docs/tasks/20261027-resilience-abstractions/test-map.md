- C：framework/tests/Bing.Resilience.Tests，Fences/Polly 同一契约方法在 net6/net8 各运行。
- H：framework/tests/Bing.Http.Resilience.Tests，HTTP 中性集成及 Fences 实现；Polly HTTP 另由独立包消费者验证。

- 证据：evidence/final-tests 下每项目 TRX 与 tests.json；最终包消费路径由 evidence/package-evidence.json 指定。

## 包、样例和非行为性文件

- 四新增 csproj 的 TFM/依赖、两个 HTTP 包重构依赖：verify-packages.mjs 的 pack、restore、run、publish、assets/deps/nuspec 检查；Fences/Polly 独立 Generic/HTTP 消费者。
- ProviderShared 编译不引入另一个引擎：免费消费实际 assets/nupkg/deps 检查；核心无引擎反射测试。
- Bing.All.slnx、包 README、指南/迁移：文档链接、UTF-8 与 diff check；不以单元测试宣称文档正确。
- 通用和 HTTP 样例 Program、HttpHedgingDemo、ResourceProbe：verify-samples.mjs 实际运行及 evidence/samples 日志。
- 旧 Bing.DynamicApi.Client.Tests、Bing.DynamicApi.WebApiClient.Tests 双框架完整回归证明 Legacy、文件与公开契约继续兼容。

本映射涵盖所有新增生产类型和关键成员；并非行覆盖率报告。不会把历史测试通过、测试名称或 package restore 单独当作行为验收。
