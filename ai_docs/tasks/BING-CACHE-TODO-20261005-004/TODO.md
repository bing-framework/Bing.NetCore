## 已明确的使用边界

- 同步工厂及异步委托返回 Task 前的同步阻塞无法安全抢占；到期拒写，但 gate/额度需等用户代码返回后释放。
- 同键等待不占不同键准入额度；不同键嵌套工厂可能耗尽同一预算，需避免相互等待并依赖明确等待超时。
- 租约为幂等缓存回源协调，故障转移下不保证严格一次执行；显式写入成功后失效通知失败无法撤销 Redis 提交。
- Hybrid 最终一致；订阅连接断线/恢复可清空本地层，连接仍存活的消息丢失没有立即检测保证。
- SCAN 非快照，Clear 非原子；提前停止流式消费不能完成全拓扑结束校验。List 最终结果仍为 O(N) 内存。
- 故障迁移、重启及大规模测试保留独立环境门控；未开启而跳过的用例不计通过。
