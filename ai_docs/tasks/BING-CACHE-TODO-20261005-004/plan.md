## Phase 1：正确性

- T01 Hybrid 回填：同步/异步批量和扫描不得以默认 TTL 延长分布式值生命周期；采用分布式层读取时的剩余 TTL，并扣除读取/回填耗时，过期或未知 TTL 不回填。补短 TTL 和缺失清理测试。范围 CacheManager、Cluster helper、EasyCaching.Tests。
- T02 回源生命周期：统一从工厂调用前起算 RetrievalTimeout；同步调用不强制中止用户线程，但到期停止续租并禁止写回，明确协作边界。异步工厂超时/取消及时返回，观察遗留任务异常并取消计时任务；清理失败保留原异常，成功路径清理失败明确传播。范围三 Provider 协调与公共内部 helper；补配置上界、超时、取消、失租、异常优先级测试。
- T03 在途回源顺序：普通 Set/删除撤销同键租约，避免旧回源覆写新值或复活删除值；Redis 原子脚本同槽执行，TrySet 仅成功时撤销。批量、前缀删除调用同一语义。测试暂停回源后 Set/Remove；Clear 保留既定非原子并发写入边界。
- T04 序列化：独立值保持独立反序列化上下文，不以拼接数组改变 JSON converter/reference 语义。同步/异步/List/Stream 使用同策略，补自定义转换器、引用元数据、nullable/DTO/坏值直接测试。
